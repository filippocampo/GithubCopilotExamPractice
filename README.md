# GitHub Copilot Exam Practice

Desktop app per esercitarsi sui temi della certificazione GitHub Copilot.

Pensata per ripassare in modo rapido, con un pacchetto Windows gia pronto all'uso: scarichi lo ZIP, lo estrai e avvii l'applicazione.

## Download

[Scarica GithubCopilotExamPractice.zip](GithubCopilotExamPractice.zip)

Dimensione pacchetto: circa 20 MB.

## Come Si Usa

1. Scarica `GithubCopilotExamPractice.zip`.
2. Estrai tutto il contenuto dello ZIP in una cartella a tua scelta.
3. Avvia `GithubCopilotExamPractice.exe`.

Non serve installare Python o altre dipendenze: sono incluse nel pacchetto.

## Requisiti

- Windows 10 o successivo.
- Spazio libero sufficiente per estrarre lo ZIP.
- Permessi per eseguire applicazioni scaricate da Internet.

## Cosa Contiene Il Pacchetto

- `GithubCopilotExamPractice.exe`, l'applicazione da avviare.
- `_internal/`, la cartella con runtime, librerie, asset e database delle domande.

Importante: dopo l'estrazione, lascia `GithubCopilotExamPractice.exe` e `_internal/` nella stessa cartella. Se separati, l'app potrebbe non avviarsi correttamente.

## Note Di Sicurezza

Windows potrebbe mostrare un avviso perche l'eseguibile non e firmato digitalmente. Prosegui solo se hai scaricato il pacchetto da questo repository e ti fidi dell'origine.

Il progetto non richiede credenziali, token o chiavi API per essere eseguito.
